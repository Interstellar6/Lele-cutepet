附录 C · Canvas 速成

Canvas 是新手最容易懵的地方，因为它和 HTML 的思维方式不一样： 它不是「摆元素」，而是「在一张纸上画」。

第一件事：它不是元素，是像素

你画上去的东西，浏览器只记得像素，不记得「这是一个圆」。 所以想动起来，每一帧都得先擦干净、再重画一次： 

ctx.clearRect(0, 0, 宽, 高);   // 擦掉上一帧
ctx.drawImage(skin, 0, 0, W, H);   // 画这一帧

坐标系：左上角是 (0, 0)，y 往下变大

数学课上 y 往上，网页里 y 往下。记住这一条，很多「怎么反了」的问题就通了。

ctx.fillRect(0, 0, 50, 50);        // 左上角一个 50×50 的方块
ctx.fillRect(100, 100, 50, 50);    // 右边 100、下边 100 的位置

尺寸要设两次

canvas.width  = W * DPR;            // 后备缓冲（真实像素）
canvas.height = H * DPR;
canvas.style.width  = W + 'px';     // 画在页面上的可见大小
canvas.style.height = H + 'px';
ctx.setTransform(DPR, 0, 0, DPR, 0, 0);   // 之后都按「逻辑像素」思考

只设第一个，图会被放大糊掉；只设第二个，会糊得不一样。 DPR 是屏幕像素比，Mac 上一般是 2。

核心门槛：translate / scale / rotate 变的是「坐标系」

它们不是「移动这个图形」，而是把整张纸挪一下、缩放一下、转一下， 之后画的所有东西都按新的坐标系来。用鼠标拖下面的滑块感受一下：

蓝点是锚点。压扁时勾不勾这个开关，看看脚有没有离开地面。

对应的代码就是这三行 —— 注意三条的顺序不能换：

ctx.translate(锚点x, 锚点y);      // ① 把原点搬到锚点
ctx.rotate(旋转);                 // ② 转（绕着新原点 = 锚点）
ctx.scale(横向缩放, 纵向缩放);     // ③ 缩放（也是绕锚点）
ctx.translate(-图形宽/2, -图形高); // ④ 把图形摆回原点附近
ctx.fillRect(0, 0, 图形宽, 图形高);
💡
只看一句话就够 锚点在哪，缩放和旋转就绕哪。 桌宠把锚点放在脚底中心，所以压扁时脚不离地； 放正中间就会整个悬空 —— 上面那个开关就是在演示这件事。

save / restore：给坐标系做「存档」

改坐标系会影响后面画的所有东西。画完一个部件想回到原状， 就用 save() 存档、restore() 读档： 

ctx.save();                       // 存一下当前坐标系/颜色/透明度
ctx.translate(100, 100);
ctx.rotate(0.5);
ctx.fillRect(0, 0, 40, 40);        // 这些变换只影响这里
ctx.restore();                     // 回到存的时候

ctx.fillRect(0, 0, 40, 40);        // 又回到没变换的状态

它是栈：可以连续 save 好几层，restore 一次退一层。 忘了 restore 是新手最常见的 bug（后面的东西全都歪了）。

drawImage：把图片画进去

最常用的两个版本：

// 三参数：原图 → 目标位置（自动按原尺寸）
ctx.drawImage(img, x, y);

// 五参数：原图 → 目标位置 + 目标宽高（最常用，可以缩放）
ctx.drawImage(img, x, y, 宽, 高);

本项目的眼睛就是五参数版：高度乘上「张眼程度」，就完成了眨眼（见 附录 B 之后的 V2）。

渐变：一条线都不用手画

const g = ctx.createRadialGradient(cx, cy, 1, cx, cy, r);
g.addColorStop(0, 'rgba(70,60,95,.30)');   // 中心 30% 黑
g.addColorStop(1, 'rgba(70,60,95,0)');     // 边缘透明
ctx.fillStyle = g;
ctx.beginPath();
ctx.arc(cx, cy, r, 0, Math.PI * 2);
ctx.fill();

影子、腮红都是这么画出来的 —— 一个圆 + 一圈透明的渐变，比画贴图省事。

合成模式：只画在「已有像素」上

ctx.globalCompositeOperation = 'source-atop';  // 只画在已有内容上
// ……画腮红……
ctx.globalCompositeOperation = 'source-over';  // 记得改回来

腮红要贴在猫脸上、又不能糊到画布空白处 —— 不用抠形状，换个模式就行。

动手改改看

打开 build/01-呼吸.html，找到这段，把 PAD_T 改成 0：

const PAD_T = Math.round(H * 0.32);   // 改成 0 试试：头顶会被裁掉

刷新 —— 猫的耳朵不见了。这就是「画布要比角色大一圈」的原因。
