附录 A · HTML / CSS 速成

没写过网页也能看懂：这一页只讲本项目用到的那些，其余的不用管。 HTML 管结构，CSS 管摆放。

📌
读法建议：先扫一眼，遇到不懂的再回来查。 教程里出现陌生的写法时，每一页都会用这个小蓝框把你指回来。

HTML：它就是个「盒子嵌套」

所有网页都是这样一层套一层。本项目第 1 版的结构只有四个盒子：

<div id="desk"></div>              <!-- 桌子 -->
<div id="stage">                    <!-- 舞台：装着猫 -->
  <canvas id="c"></canvas>           <!-- 画布：猫画在这里面 -->
  <div id="hit"></div>               <!-- 命中区：接鼠标点击 -->
</div>
<p id="tip">第 1 版 · 点它一下会挤压</p>
你看到的叫什么说明
<div>标签（tag）一个方块，什么都不会显示，用来装东西
id="c"属性（attribute）给这个盒子起个唯一的名字，JS 靠它找到它
<!-- … -->注释不会显示，写给人看
<canvas>画布特殊盒子，可以在里面画像素
💡
id 和 class 的区别 id 全页只能有一个，JS 用 getElementById('c') 取； class 可以贴在很多元素上，CSS 用它来批量套样式。

CSS：一条规则 = 选中谁 + 怎么摆

#desk {
  position: fixed;          /* 固定贴在窗口上，滚动也不动 */
  left: 0; right: 0;        /* 左右都拉到边 = 占满宽度 */
  bottom: 0;                /* 贴住窗口底部 */
  height: 22vh;             /* 高度 = 窗口高度的 22% */
  background: linear-gradient(180deg, #f7ecdf, #efdfcd);
}

#desk 就是「选中 id 叫 desk 的那个元素」（# 表示 id）。 大括号里一行一个属性，属性: 值;。

单位：px / % / vh

写法意思用在哪儿
220px220 个像素，绝对大小角色多宽、留白多少
22%父盒子的 22%——
22vh窗口高度的 22%（v = viewport）桌子占多高
0.32（在 JS 里乘）比例，跟着尺寸变留白 = 身高 × 0.32

定位：为什么猫能浮在桌子上

position 决定一个盒子怎么摆。本项目只用了三种：

取值行为本项目用在哪
static（默认）按顺序往下排文字、段落
fixed钉在窗口上，不随滚动桌子、舞台、提示文字
absolute钉在最近的 position 祖先上命中区、气泡（相对舞台定位）
⚠️
最容易踩的坑 一个 absolute 的元素，会相对最近的已定位祖先定位。 父元素没写 position 的话，它会跑去找更外层，位置就莫名其妙了。 本项目的 #stage 写了 position: fixed, 所以里面的气泡和命中区都老老实实跟着它。

transform：移动 / 缩放 / 旋转

本项目的舞台用 transform 来移动，而不是改 left/top： 

stage.style.transform = 'translate3d(' + x + 'px,' + y + 'px, 0)';
改 left/top改 transform
浏览器要做什么重新算整个页面的排版只挪动这一层（走 GPU 合成）
每帧都改会卡很顺
和 CSS 动画叠加容易打架互不干扰

所以你会在桌宠、地图、动画里到处看到 transform。 另外它不影响其他元素的排版，挪走以后原来占的位置还在。

transition：让状态变化「滑」过去

气泡就是靠这个「弹出来」的，一行 CSS 换来手感：

#bubble {
  opacity: 0;                                        /* 默认透明 */
  transform: translate(-50%, 6px) scale(.86);        /* 默认小一点、低一点 */
  transition: opacity .16s, transform .22s cubic-bezier(.2, 1.5, .4, 1);
}
#bubble.on {
  opacity: 1;                                        /* 加上 on 类就显示 */
  transform: translate(-50%, -2px) scale(1);
}

JS 只负责 classList.add('on')，剩下的过渡浏览器帮你算。 cubic-bezier(.2,1.5,.4,1) 就是那个「弹一下」的感觉。

z-index：谁压着谁

数字大的在上面。本项目的 #desk 是 z-index:1， 舞台没写 z-index 但在 DOM 里排在后面，所以猫压在桌子上。 桌宠组件用的是 2147483000 —— 一个「不会被人盖住」的夸张数字。

动手改改看

打开 build/01-呼吸.html，按 F12 打开开发者工具，在 Elements 面板里：

  1. 选中 #desk，把 height: 22vh 改成 40vh —— 桌子变高，猫不变；
  2. 选中 #stage，给它加一条 filter: blur(2px) —— 整只猫跟着糊（因为 canvas 在它里面）；
  3. 选中 #tip，改文字看看。

改完刷新就还原了，随便试，不会弄坏东西。
