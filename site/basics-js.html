这一页只讲本项目真的用到的语法。每一条都配了项目里的一行真实代码 —— 你看不懂哪行，就在这页搜它的关键字。

变量：const 和 let

const SPRITE = { w: 811, h: 792 };   // 不会再重新赋值的，用 const
let bob = 0;                          // 会变的，用 let
bob -= Math.sin(time * 2.1) * 1.4;

const 是「这个名字以后只指向这个东西」，不是「内容不能改」—— 对象里的值照样能改。习惯上默认写 const，确实要重新赋值再改 let。

对象：一堆「键: 值」

本项目的状态几乎都是对象。这是桌宠的全部状态：

const pet = {
  x: 500, y: 300,        // 位置
  state: 'idle',         // 状态：idle / drag / fly
  vx: 0, vy: 0,          // 速度
  facing: 1              // 朝左(-1)还是朝右(1)
};

pet.x += 10;             // 用「点」取值和改值
pet.state = 'fly';

函数：把一堆步骤打包

// 普通函数
function floorY() {
  return window.innerHeight * 0.78 - H;
}

// 箭头函数：同样的东西，短一点
const clamp = (v, a, b) => (v < a ? a : v > b ? b : v);

clamp(v, 0, 1) 是「把 v 卡在 0 和 1 之间」的常用小工具， 本项目到处在用（限制眼睛偏移、限制透明度……）。

数组：一串东西，用［］取

const lines = ['嘿嘿～', '好开心！', '喵呜～'];

lines[0];                          // '嘿嘿～'
lines.length;                      // 3
lines[(Math.random() * lines.length) | 0];   // 随机抽一句

samples.push({ t: now, x: e.clientX });      // 往尾部加一个
samples.shift();                             // 从头部删一个

那个 | 0 是「取整」的偏方，等价于 Math.floor()， 写在 Math.random() * 3 后面就是「随机取 0、1、2 之一」。

找到页面上的元素，然后听它的事件

const canvas = document.getElementById('c');        // 按 id 找
const ctx = canvas.getContext('2d');                 // 拿到画笔

const hit = document.getElementById('hit');
hit.addEventListener('pointerdown', (e) => {         // 按下时执行
  e.preventDefault();                                 // 别做默认行为（比如拖动图片）
  pet.squash = { t: 0, dur: 0.45, amp: 0.22 };        // 挤压一下
});
写法意思
addEventListener('pointerdown', fn)按下（鼠标/手指都算）
'pointermove'移动
'pointerup'松开
e.clientX / e.clientY事件发生时，指针在窗口里的坐标

为什么不用 mousedown？因为 pointer 事件鼠标、触摸屏、触控笔统一处理， 手机上一套代码就够。

每帧跑一次：requestAnimationFrame

动画的本体就是一个「自己调自己」的循环：

let last = performance.now();
let time = 0;

function frame(now) {
  const dt = Math.min(0.05, (now - last) / 1000);   // 距上一帧过了几秒
  last = now;
  time += dt;

  draw();                                  // 画这一帧
  requestAnimationFrame(frame);            // 约 60 次/秒，下一帧再叫我
}
requestAnimationFrame(frame);              // 启动
💡
为什么到处都在乘 dt 速度写的是「每秒移动多少像素」，所以每帧要走 速度 × 这一帧的秒数。不乘的话，120Hz 的屏幕上宠物会跑两倍快。

为什么整个文件包在一个函数里

(function () {
  'use strict';
  const W = 220;          // 这些变量外面看不到，不会污染全局
})();

这叫「立即执行函数」（IIFE）。好处：里面的 W、pet 不会和别的脚本撞名。你在教程里看到的每个版本都是这个结构。

等待图片加载：Promise / async

图片是异步加载的，不能写完 img.src = ... 就立刻 drawImage(img) —— 那时它还没加载完，画出来是空的。 

function loadImage(src) {
  return new Promise((resolve, reject) => {
    const i = new Image();
    i.onload  = () => resolve(i);        // 加载好了 → 把图片交出去
    i.onerror = reject;                  // 失败了 → 报错
    i.src = src;
  });
}

// 三张图都加载完，再开始画
Promise.all([loadImage('a.png'), loadImage('b.png'), loadImage('c.png')])
  .then((arr) => {
    skin = arr[0]; eyeL = arr[1]; eyeR = arr[2];
    requestAnimationFrame(frame);
  });

.then(...) 里的代码会在「前面的事都完成」之后才执行。 这就是为什么本项目的动画一定要在 .then 里启动。

写法作用项目里用在哪
Math.sin(t)-1 到 1 之间来回摆呼吸、抖动
Math.abs(x)绝对值速度大小、走路起伏
Math.round(x)四舍五入成整数像素对齐
Math.min / max取小 / 取大限制不超出范围
