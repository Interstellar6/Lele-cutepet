附录 D · 调试

写网页最花时间的不是「写」，是「为什么没反应」。 这一页把新手最常遇到的几种情况列出来，对照着查就行。

先学会开控制台

系统快捷键
MacCmd + Option + I → 选 Console
Windows / LinuxF12 或 Ctrl + Shift + I → Console
任何系统右键页面 → 「检查」

Console 里出现红色，就是你唯一需要看的东西。 白屏、猫不动、点了没反应 —— 95% 的情况下红字直接告诉你哪一行错了。

四种最常见的红字

1. Cannot read properties of null (reading 'getContext')

意思是「我按 id 找那个元素，没找到，拿到个 null，然后你就让我在 null 上取画笔」。

原因怎么查
getElementById('c') 里的 id 和 HTML 里对不上两边逐字符比一遍，大小写也算
脚本跑在元素创建之前把 <script> 移到 </body> 前面

2. xxx is not a function

拼错了，或者用错了对象。比如把 ctx.drawImage 写成 ctx.drawimage。

3. Failed to load resource: 404

图片或文件路径不对。检查相对路径 —— ../assets/lele-skin.png 里的 ../ 表示「上一级目录」。
本项目的相对路径是按 build/ 目录算的： 文件在 build/01-呼吸.html，素材在 assets/，所以是 ../assets/。 你把文件挪到别处，这段就要改。

4. 不报错，但东西不动 / 不见了

没有红字反而更难查。按这个顺序怀疑：

console.log：最简单也最好用的调试

怀疑某个值不对，就把它打出来：

console.log('pet.y =', pet.y, ' floor =', floorY());

// 在动画里则会刷屏，所以只在值变化时打：
if (Math.random() < 0.01) console.log(pet.state, pet.x, pet.y);

打完记得删掉（或者用 console.table 看得更清楚）。 想看对象整体，直接 console.log(pet)，控制台能展开。

Elements 面板：直接改，马上看

打开开发者工具 → Elements，选中一个元素，右边就能改 CSS。 改完立刻生效，刷新就还原 —— 调样式最快的办法，比改文件 → 刷新快十倍。

本项目调参时特别有用，比如：

  • 改 #desk 的 height，看桌子高度怎么影响站位；
  • 给 #stage 加 outline: 2px solid red，看清画布的边界（连留白一起）；
  • 给 #hit 加背景色，看清命中区到底覆盖了哪里。
💡
本项目故意留了两个「探针」 打开成品页或教程站，在 Console 里输入： lele.poke()（成品页）、tutPet.poke()（教程站）， 就能不点鼠标直接逗它。想试某个 API，不用改代码。

调参的工作方式

做完前面五版你会发现，剩下全是「改一个数，看一次效果」。这个循环是：

改一个常量比如 G = 2600
→
保存 + 刷新或直接改 DevTools
→
看手感对不对大了还是小了
→
再改一次

所以我在代码里把能调的数值都提到了顶部当常量： G、BOUNCE、PAD_*、W。 调参时只碰这几个地方，不要到处乱改。

术语小抄

元素 / element
页面上的一个盒子，比如 <div>、<canvas>。
选择器 / selector
「选中谁」的写法：#c 是 id，.note 是 class，div 是标签名。
坐标系 / transform
canvas 里所有绘制都发生在一个「会变形的坐标系」里；translate/rotate/scale 就是在改它。
锚点 / anchor / origin
缩放和旋转围绕的那个点。本项目是「脚底中心」。
精灵 / sprite
那张抠好的角色图（本项目 811×792）。
留白 / padding（这里的 PAD_）
画布比角色多出来的那一圈，避免动作被裁掉。
帧 / frame、帧率 / fps
每秒画多少次。浏览器一般 60 次；每帧的时间就是 dt。
DPR / devicePixelRatio
一个 CSS 像素对应几个物理像素。Mac 高分屏是 2。
Promise / 异步
「这件事要等一会儿」。图片加载就是异步的，所以要用 .then 等它。
闭包 / IIFE
把代码包进 (function(){ … })()，里面的变量外面看不到，避免撞名。
合成模式 / composite
source-atop 这种，决定「新画的像素和已有的像素怎么叠加」。

还是一动不动？

🔍
三步定位法 ① Console 有没有红字 → 有就照着改；
② Elements 里选中 #stage，看它的 transform 有没有在变 → 不变说明动画循环没跑起来；
③ 在循环第一行加 console.log(1) → 不打印说明 requestAnimationFrame 没启动（多半是图片没加载成功，.then 没进）。
