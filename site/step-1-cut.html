第 1 步 · 抠图：把猫拿出来

目标只有一个：得到一张只有猫、背景透明的 PNG。

为什么不能「按白色抠掉」

这是只白猫，背景也是白灰。如果简单地「接近白色就变透明」，猫的毛边会跟着一起被抠掉， 边缘变成锯齿，脸上还可能出现透明的洞。

正确做法是从图片四条边往里灌水：

  • 先按「和背景色的距离」判断每个像素像不像背景；
  • 只把和图片边缘连通的那些背景变透明；
  • 猫身体内部的浅色毛因为被深色毛包住，灌不进去，所以不会破洞。

原图左上角还贴着一个「乐乐」对话气泡。它和耳朵之间只连着几个像素， 所以脚本会先腐蚀 6px 把这根细线断开，从猫身上灌水，再膨胀回来 —— 气泡就被甩掉了。

跑起来

先看一张带坐标网格的图（下一步量眼睛要用），再正式抠：

# 1) 出网格图，用来量眼睛坐标
python3 tools/split-sprite.py --src assets/lele-original.jpg --out /tmp/pet --grid

# 2) 正式抠图
python3 tools/split-sprite.py --src assets/lele-original.jpg --out /tmp/pet \
    --seed 540,700 --preview

--seed 是「猫身上的一个点」，脚本从这里开始灌水。 这张图给的是鼻头 540,700；不给的话默认取图片中心， 如果中心正好是背景，就会抠空。

看结果

终端会打印外接框，比如这张图：

背景色估计：[228.5 229.  236. ]  容差 22.0
角色外接框：(166, 327, 977, 1119)  尺寸 811x792
  lele.png        (811, 792)

再用 --preview 生成的对照图验收：左边是抠图，中间是「皮 + 眼睛」， 右边两格是眨眼的过程。看一眼就知道干不干净。

✅
合格的标准 背景全透明、毛边有半透明过渡、没有残留的卡片角或文字。 把这张 PNG 拖进浏览器，背景应该是灰白格子。

抠坏了怎么办

症状原因改法
抠出来只有一小块 种子点落在背景上了 --seed x,y 指到角色身上
背景没抠干净 / 毛被吃掉 背景不是纯色 --tol 调大或调小（默认 22）
旁边有块东西跟着留下 它和角色连在一起 调大脚本里的腐蚀半径 grow_erode
整张图糊成一块 背景太花（截图） 见下一节

背景不干净：两条出路

我实测过：拿一张带白色卡片、文字、UI 的微博截图去抠，必然失败 —— 因为「背景」根本不是一个颜色。这时候别硬抠： 

# 出路 1：先裁到角色，让背景尽量均匀（坐标按原图给）
python3 tools/split-sprite.py --src shot.jpg --out pet \
    --crop 68,110,246,296 --seed 157,268 --tol 26

# 出路 2：外部蒙版（白=角色，黑=背景）
#   先装 rembg 出一张蒙版，再喂进去
pip install rembg
rembg i shot.jpg mask.png
python3 tools/split-sprite.py --src shot.jpg --out pet --mask mask.png
💡
小技巧 Photoshop / 像素级选择工具 / 在线抠图站也能出蒙版， 存成黑白 PNG 就能用 --mask。别在这步死磕算法。

拿到干净的 pet.png 就完成一半了。下一步把眼睛拆出来。
