第 6 步 · 换成你的图 · 调参

从这一页起，你不需要懂前面的原理了 —— 换三个常量、拖几个滑块，就是另一只桌宠。

换成你的图：三步

  1. 拆素材

    用第 1、2 步的命令，把新图拆成四张 PNG。别忘了先 --grid 量眼睛。

  2. 抄常量

    打开它生成的 pet.json，把 size 和两个 box 抄进你的 JS 顶部：

    const SPRITE = { w: 811, h: 792 };                            // ← 换掉它
const EYES = {
  l: { box: [154, 156, 362, 352] },                          // ← 换掉它
  r: { box: [521, 176, 709, 360] }                           // ← 换掉它
};
const CHEEKS = [{ x: 186, y: 356, r: 96 }, { x: 672, y: 372, r: 92 }];  // 腮红，看着调

  3. 改台词

    见下面「改台词」一节。改完刷新页面就生效。

💡
只有这三组常量跟「是哪只动物」有关 其余代码（眨眼、视线、物理、台词调度）全都是通用的，一行都不用改。

改台词

        

          所有台词都在一个对象里，按场景分组。传进 lines 就覆盖，
          没传的沿用默认。
        


LelePet.mount({
  base: 'assets/',
  lines: {
    poke: ['别戳我！', '喵？'],          // 点它一下
    pat:  ['呼噜呼噜…', '再来'],         // 摸它
    sleep:['Zzz…', '困了'],             // 睡着
    idle: ['该休息啦', '记得存盘']        // 没人理它时自言自语
  }
});

// 可以改的 key：
// hello poke happy shy angry giggle pat drag fly land sleep wake idle

roamtrue自己散步

            
sound / volumetrue / 0.3音效与音量

            
dockfalse悬停小工具条

            
greettrue出现时打招呼

            
fixedtruefalse = 随文档滚动

            
posKey'lele-pet-pos'位置记忆；null = 不记

            
zIndex2147483000层级

            
onSay / onPoke—回调

          

        


        
常用 API


const pet = LelePet.mount({ /* 上面的配置 */ });

pet.say('写完了记得提交');   // 说一句
pet.pat(true);              // 摸一下（true = 忽略冷却）
pet.hop();  pet.spin();     // 蹦 / 转圈
pet.sleep(); pet.wake();    // 睡 / 醒
pet.walkTo(600);            // 走到某个 x
pet.setSize(260);           // 改大小
pet.setVolume(0);           // 静音
pet.hide(); pet.show();     // 藏起来 / 叫回来
pet.destroy();              // 彻底移除

让宠物站在某个元素上

        

          floor 决定它踩在哪条线上。传选择器最方便 —— 比如让它站在页面底部的
          #desk 上：
        


LelePet.mount({
  base: 'assets/',
  floor: '#desk',            // 踩在 #desk 的上边缘
  x: 0.8
});

// 也可以给函数，动态决定（比如跟着某个卡片走）
LelePet.mount({
  floor: function (pet) {
    var r = document.querySelector('#desk').getBoundingClientRect();
    return r.top;
  }
});
